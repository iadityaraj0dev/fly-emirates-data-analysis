# ✈️ Fly Emirates Data Analysis

## Project Overview
This project focuses on analyzing aviation-related data using SQL, PostgreSQL, and Power BI to explore flight, airline, and airport information and present findings through an interactive dashboard.

## Objectives
- Explore flight and aviation data.
- Query and analyze related datasets using SQL.
- Organize and prepare data for reporting.
- Present analysis through Power BI visualizations.

## Tools & Technologies
- **SQL** — Data querying and analysis
- **PostgreSQL** — Relational database management
- **Power BI** — Interactive dashboard and data visualization

## Repository Structure
- `sql/` — SQL scripts used in the project
- `powerbi/` — Power BI dashboard file
